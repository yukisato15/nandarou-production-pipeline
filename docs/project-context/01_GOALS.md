# Goals

## 短期（現在の制作を完了する）

1. 第1回のRemotion対象カットを、入力JSONと実写素材の境界を明確にして納品する。
2. C25（商品そのもの→なれる自分）、C18（人間の仕様）、C42（箸休め）の不足カットを、スタイルフレーム承認後に実装する。
3. 第1回・第2回のテロップを、`conte2telops.py`とカット単位レンダーで再現できる状態にする。
4. アイキャッチ（`NandarouKaitaiIdent`）を、音源・フレーム・レイアウトの検査可能な状態で維持する。

## 中期（第2回以降の再利用）

- JSONだけを差し替えて、登録済みのタイトル、引用、数字、棒グラフ、折れ線、宣言、偽サムネ、スマホフィードを制作する。
- 新しい画は、静止画の人間承認→コンポーネント化→レジストリ登録の順で増やす。
- Premiereでの合成、音、呼吸、最終判断を維持し、Remotionを編集判断の代替にしない。
- 実写・静止画・紙・数字・注釈を合成する資料モンタージュ基盤を設計から実装へ進める。

## 長期

- 15回の番組制作で同じブランドと品質を保てる永続資産にする。
- AIが途中参加しても、JSONスキーマと検証ゲートを守って安全に作業できる状態にする。
- 必要に応じてクラウドレンダーへ拡張する。ただしCloud Run/Lambdaの実装は現時点でこのリポジトリに確認できない。

## 現在の優先順位

1. 入力と尺の整合、可読尺、カット単位納品を壊さない。
2. 第1回の未出力カットを棚卸しし、完成・仮・旧成果物を分ける。
3. C25 → C18 → C42の順にスタイルフレームを承認する。
4. 第2回テロップを同じ実証済み手順で作る。
5. その後に汎用モンタージュ型を拡張する。
