# リポジトリ整理指示書 v1

2026-07-17 / 対象: `nandarou-production-pipeline` main 目的: **入力(コンテ・素材・文書)と出力(再生成物)を構造で区別できる状態にする。** 旧路線のファイルは削除せず `archive/` へ隔離する(いずれ削除予定)。

実行前に AGENTS.md §8(人間ゲート)と §10(コミット規約)を再読すること。

---

## 0\. 原則(この整理の判断基準)

1. **スクリプトから再生成できるものは git 管理しない**(.gitignore 化して削除。履歴には残る)
2. **旧路線・役目を終えたものは `archive/` へ移動**(削除しない。理由を README に記録)
3. **参照されている素材はコードが動く場所から動かさない**(remotion\_mg/public/ 配下は原則現状維持)
4. 移動に伴うパス参照の更新は**機械的な置換+検証ゲート**で担保する。黙った修正・独自判断の追加変更は禁止

## 7\. コミット・報告規約

- コミットは意味単位で分割: ①archive隔離 ②出力物のgit管理外化 ③現役ファイル移動+参照更新 ④ドキュメント更新 の4つ目安
- **force push 禁止。ブランチを切って PR にする**(例: `chore/repo-reorg-v1`)。マージは Yuki
- 未コミットのローカル変更があれば作業前に報告し、勝手に stash・破棄しない
- 完了報告に含めること: 移動ファイル一覧(git status \--short)、§2-D の未参照画像リスト、検証ゲート7項の結果
