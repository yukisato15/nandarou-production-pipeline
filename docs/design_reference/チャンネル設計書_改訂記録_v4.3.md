## 改訂: 尺規定 —「8分前後」から「密度ゲート型」へ

**旧(v4)**: 1回8分前後。

**新(v4.3)**:

1. **基準は8〜10分。ただし内容の因果線が要求する場合、上限は設けない。**
   尺を決めるのは時間ではなく「語るべき因果の鎖が何本あるか」
2. **密度ゲート(延長の条件)**: 尺を伸ばす場合、全カットが次のテストを通ること
   - 「このカットを削ると、因果線が切れるか?」——切れないカットは削る
   - 美学3問(「言われていないもの」に触れているか/静かか/作り方を見せられるか)
3. **チャプター必須**(10分超の回): 概要欄にチャプターを設定し、各章タイトルは問いの形にする
   (視聴者が「調べ直す」ためのインデックス=誠実の実装。離脱対策も兼ねる)
4. **実測での検証**: 公開後、リテンションカーブを確認し「どの章で切れたか」を次回の尺判断に反映する
   (延長は仮説。データで答え合わせする)

## 根拠(記録として)

- エバーグリーン・検索流入型の解説コンテンツでは、12〜18分は総再生時間シグナル・ミッドロール広告(8分以上)の点でむしろ有利
- 「このチャンネルはここまで調べる」を宣言回で示すことは、ブランド定義(誠実・作り方を見せる)と一致する
- 一方で尺の無条件解禁は編集の緩みを生むため、「密度ゲート」を通過条件として残す
- コスト認識: 尺1.5倍=カット数・テロップ・MG・素材もほぼ1.5倍。延長は制作計画(スケジュール・素材調達)とセットで決定すること
