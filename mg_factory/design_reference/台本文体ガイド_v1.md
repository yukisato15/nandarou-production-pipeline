# 『なんだろう』解体 台本文体ガイド v1

2026-07-13 / 第1回・第2回の完成台本から抽出。

## 0. 声の正体(これだけは外さない)

語り手は**元・地方ケーブルテレビのカメラマン/制作者**。15年間、作る側にいた人間が、
YouTubeに来て驚き、調べ始めた——その記録として毎回が語られる。

- **教えない。一緒に調べる。**(「教えるんじゃなくて、一緒に、調べていく。」)
- **怖がらせない。タネ明かしする。**(「この動画の目的は、怖がらせることではありません。★怖がらなくて済むように、することです。」)
- **自分も仕組みの中にいると白状する。**(「白状すると、この動画のサムネも、同じ手口で作っています。」)

この3つが崩れた台本は、文法が正しくても番組の台本ではない。

## 1. 基本ルール

| 項目 | ルール |
|---|---|
| 一人称 | 「ぼく」(ひらがな)。制作者仲間を含むときは「ぼくら」 |
| 二人称 | 「あなた」。視聴者を「みなさん」と呼ばない |
| 文体 | です・ます基調。ただし断言は短文・体言止めで切る |
| 文の長さ | 1文は短く。長い説明は「。」で割る |
| 断言(★文) | 1カットに1つまで。比喩は具体物に落とす(エサ/燃料/撒き餌/タネ/値札) |
| 数字 | 具体的に(「15年」「約12万件」「50万件」「5倍」)。盛らない |

## 2. リズムの規則(実例つき)

**読点で息継ぎを刻む。** ナレーターが読む台本なので、読点=間。
> なぜ、みんな、数字に取り憑かれてしまうんだろう。
> 怒る相手を、機械が、あなた専用に選んでくるんです。

**「——」は思考の間・転調に使う。**
> それで、YouTubeを始めてみて——正直、驚いたんです。
> 結果は——

**短い断言で切る。直前まで説明、最後に一撃。**
> 人間の、仕様です。
> 人間に、市場価値。——よく考えると、すごい言葉です。

**同じ語を3回畳みかける(反復のリズム)。**
> つい見てしまう。つい確かめてしまう。つい、誰かに送りたくなる。
> わざと下手な料理を作る。わざと間違ったことを言う。わざと、怒らせる。

**問いかけで橋を架ける。**
> ——100年前の話に、聞こえるでしょうか。
> ——昔話に、聞こえるでしょうか。今日の、トレンド欄と見比べてみてください。

## 3. 構成の型(P0〜P5)

第1回・第2回は完全に同じ骨格を持つ。**新しい回もこの骨格から始めること。**

| パート | 中身 | 定型句(ほぼ固定) |
|---|---|---|
| P0 フック | ①煽り文言を3連で提示(「日本、終わる」/「は?」)→②「——こういう○○、ないでしょうか。」→③**白状すると**(自己開示)→④経歴1文→⑤「なぜ、〜んだろう。」→⑥タイトル提示 | 「ここから、始めます。」 |
| P1 仕組み | ①「まず、結論から言います。」→②★比喩宣言(不安=エサ/怒り=燃料)→③研究・データ(出典明示)→④「気のせいでは、ありません。」→⑤人間の仕様の話→⑥**後半への予告**を1つ置く | 「ひとつだけ、先に言っておくと。★〜」「その話は、あとで。まずは、N年前に遡ります。」 |
| P2 歴史 | 実在の人物と逸話(バーネイズ/ハースト/ゲッベルス/ラジオ神父)→現在への接続→現代事例(選挙・アルゴリズム) | 「——昔話に、聞こえるでしょうか。」 |
| P3 現在 | ①「さて——さっきの予告を、回収します。」→②予告した★文を同じ言葉で再提示→③身近で奇妙な実例(友達レンタル/スマイル0円/レイジベイト) | |
| P4 処方 | ①「今日、覚えて帰ってほしいことは、三つです。」→②★ひとつ。/★ふたつ。/★みっつ。(みっつ目は必ず希望)→③**自己開示の回収**(「ぼくも、調べるまでは、怖かったんです」)→④処方は小さく具体的に | |
| P5 締め | チャンネル定型文(下記・固定)→透明性宣言→次回予告 | 「それでは、また次回。」 |

**P5の固定文(変えない):**
> このチャンネル——『なんだろう』解体では、こういう「なんだろう」を、ひとつずつ、構造から解体していきます。教えるんじゃなくて、一緒に、調べていく。

> 台本と出典は、概要欄からぜんぶ読めます。どこまでが研究や報道で、どこからがぼくの解釈か。間違っていたら、次の動画の頭で、訂正します。

## 4. 留保の作法(法務と信頼の生命線)

断定できないことは、**断定しない構文**で書く。実例:

- 研究の要約: 「〜広がっていた——**と、されています**。」
- 逸話: 「ハーストがそう言った、**という逸話まであります。実話かは、怪しい。**でも、そんな逸話が生まれるほどの、商売だったということです。」
- 評価が割れる話: 「選挙結果をどこまで動かしたのかは、**専門家でも意見が分かれています**。ただ——その手口が実際に使われたことは、**事実です**。」
- 国内の係争中事案: 固有名を出さない+「本人は関与を否定していて」+「★何が事実かは、まだ確定していません。」の**三点セット**

留保したうえで「何が確かか」を1つだけ言い切るのがこの番組の型
(「ただ、ひとつだけ、確かなことがあります。」)。

## 5. 語彙

**使う**: 具体物の比喩(エサ・燃料・撒き餌・タネ・値札・ピース)、
「つい」「仕組み」「構造」「解体」「白状する」「回収する」

**使わない**:
- 煽り語を地の文で使わない(「ヤバい」「衝撃」「終わる」は**引用・サムネ文言としてのみ**)
- ネット論壇の符丁(「情弱」「オワコン」「炎上商法」※レイジベイトのような定義済み用語は定義してから使う)
- 上から目線(「知らないと損」「〜すべき」)。処方は提案の形(「〜してください」は最小限、P4のみ)
- 感傷過多(「悲しい現実」「闇が深い」)。感情は視聴者に感じさせ、語り手は構造を指す
