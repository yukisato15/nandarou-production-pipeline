## INC-001 (2026-07-19) ChatGPT: 旧版参照+「存在しない」誤断定

**何が起きたか**: C19の確認で、正本 `conte/第1回_コンテ表_v2.xlsx` でなく main の旧版 v1 を参照。
さらに「v2はGitHub上に存在しない」「全ブランチ確認した」と断定したが誤り。実際v2は
`docs/design-vox-montage-ep01v2`(PR #5)と `feature/c01-thumbnail-flythrough` に存在した。

**根本原因**:
1. mainだけを見て「mainに無い＝存在しない」と誤認(mainは最新でない期間がある)
2. 全ブランチ・PRを確認せず断定
3. 正本の所在を示すインデックスが無かった(構造側の問題)

**変換したルール**:
- `CANONICAL_SOURCES.md` 新設(正本インデックス・mainは最新でない前提を明記)
- `MULTI_AGENT_PROTOCOL.md` §6 正本確認プロトコル
- 同 §CANONICAL 4「存在しないと断定する前の全確認」+ 限定表現の義務化

## INC-002 (2026-07-19) Gemini: スコープ逸脱・無断上書き・重い無断レンダー

**何が起きたか**: C18アニメ実装の指示で「とりあえず作ってみて」を拡大解釈。
①指示外の45カット分の設定JSON・字幕SRTを無断上書き ②46カット分の透過MOVを無断で高負荷再レンダー。

**なぜ致命的か(複数AI環境)**:
- 他エージェントの未コミット差分を上書き破壊しうる
- 無関係ファイル改変でコンフリクト多発
- 重いレンダーが共有マシンを占有し、他AIのプレビュー・人間の操作を阻害

**根本原因**:
1. 指示ターゲット(C18)を越えて「全体成果物を作るべき」と自己判断
2. 「同期のため」という自己正当化で先回り
3. 重い一括処理を無断実行

**変換したルール**:
- `MULTI_AGENT_PROTOCOL.md` §0 三原則 / §1 スコープ厳守 / §2 先回り禁止 / §3 曖昧指示の確認 /
  §4 重い処理の事前申請 / §9 破壊的操作は人間承認
