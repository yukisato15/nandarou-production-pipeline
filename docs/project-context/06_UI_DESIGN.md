# UI / Video Design Rules

## 基本トークン

標準パレットは紙`#E3DED1`、紙明`#EFEAE0`、墨`#0E0F10`、墨2`#17181A`、金茶`#C9A063`、朱`#B8352E`、白`#EAE6DF`、灰`#6E6D66`。実装上の唯一の基準は`src/kit/theme.ts`。

## 余白

要素を画面いっぱいに詰めず、紙面の呼吸を残す。グラフやカードの座標は各コンポーネントにあるが、画面端に重要文字を置かない。長いタイトルは`TitleCard`の実効幅計算で縮小し、テロップは自動改行・可読尺フィットの規則を優先する。

## フォント

- 本文・見出し: Shippori Mincho（Fontsourceで同梱）。
- 数字: Oswald。
- アイキャッチや劇中偽UIは専用コンポジション側でNoto Sans JP等を使う場合がある。これは標準データMGのフォント規則と混同しない。
- OSフォントや外部CDNに依存しない。

## グラフ・図説

- `BarChart`: 最大6本、数値はOswald、朱は強調行。
- `LineCompare`: 最大3系列、線の描画と終点ラベルを時間制御。
- `StatCard`: 最大4項目、大きな数字とラベルを順に提示。
- 数値には出典を付け、演出値には概念図注記を付ける。
- 画面を説明するための線や図形は、論理関係・資料構造を示す場合に限る。

## アニメーション

Remotionのframe-basedな`interpolate`/`spring`/`Sequence`を使う。CSS animationや時刻依存の乱数を使わず、同じframeから同じ絵を得る。文字送りは`Statement`の1文字2Fずらしなど、コンテ・Python側の定数と一致させる。フェードだけ、Scaleだけ、Positionだけで意味を作らない。

## テロップ

- S1はPremiere SRT。
- S2/S3/S5はTelopOverlayの透過素材。
- S4はstatement等のフルフレーム宣言。
- S6は偽サムネ/画像側の文字。
- テロップ記法は`Sn/本文`、強調は`《語》`またはモーション列の`[emph:語|朱]`。1テロップ1強調、S3/S1には強調を入れない。
- 1行に収まる場合は1行。改行は句点→読点→自然な助詞の順。読める尺をカット尺より優先する。

## UI/HUD

HUDはタイトルより控えめにし、問いの発見・構造の可視化など役割がある時だけ出す。アイキャッチのHUDやグリッチは専用Compositionの責務で、標準データMGの装飾として流用しない。
