## パート2A 欲望を発明した男——バーネイズ(3:35–6:05)

《画:1920年代ニューヨーク(AI生成・セピア)。摩天楼、群衆》

100年前のアメリカに、エドワード・バーネイズという男がいました。心理学者フロイトの、甥です。

彼の最初の大きな仕事は、商品を売ることではありませんでした。——戦争を、売ることでした。

第一次世界大戦。アメリカ政府の広報委員会に加わって、「参戦すれば、ヨーロッパに民主主義が広がる」。世論を、戦争に向けて動かす仕事です。そして彼は、言葉が大衆を動かす力を、実地で目撃しました。

戦争が終わったとき、彼が何を考えたか。晩年の、本人の言葉が残っています。

《画:S3引用カット(英文+訳。出典:BBC制作ドキュメンタリー・2002年のインタビュー映像より)》

「戦争に使えたのなら、平和のためにも使えるはずだ。ただ、プロパガンダという言葉は、ドイツ人が使ったせいで評判が悪くなった。だから、別の言葉を探した。——それが、カウンセル・オン・パブリック・リレーションズ」。

PR。広報。——ぼくらが毎日聞いているあの言葉は、プロパガンダの言い換えとして生まれました。

《画:1920年代の広告(ケチャップ・自動車・靴の実用広告風)》

当時の広告は、商品の「必要」を売っていました。料理のためのケチャップ。移動のための自動車。長持ちする靴。必要なものを、必要なだけ買う。それが当たり前の時代です。

そこに、ウォール街の銀行家が、こう書きました。1927年の、経営誌です。

《画:S3引用カット》

「アメリカを、必要の文化から、欲望の文化へ切り替えねばならない。まだ使えるものを持っていても、人々が新しいものを欲しがるように、訓練するのだ」。

——訓練。すごい言葉です。そして、この転換のいちばん巧い実行者が、バーネイズでした。

《画:たばこ・パレードのくだり(AI生成・抽象寄り)》

1920年代の終わり、たばこ会社が彼に相談します。「女性にも、たばこを吸わせたい」。女性が外でたばこを吸うのは「はしたない」と、された時代です。

バーネイズはまず、精神分析の医者のところへ行きました。返ってきた助言は、こうだったといいます。——たばこは、男性の力の象徴だ。女性にとっては、自分の「たいまつ」になる。

1929年、ニューヨークのイースターパレード。彼は若い女性たちを雇って行進に混ぜ、合図とともに、一斉にたばこへ火をつけさせました。報道各社には、事前に知らせてあります。「明日、"自由のたいまつ"が灯ります」と。

翌日の新聞が、その画を「女性解放の象徴」として全国に運びました。

★デモに見えたものは、広告でした。

彼が売ったのは、たばこの味でも、値段でもありません。★商品そのものではなくて、「それを買うと、どんな自分になれるか」を売る。

《画:一瞬で現代へ。フィードを流れる広告とインフルエンサー投稿(自作モック)。カットは鋭く》

——100年前の話に、聞こえるでしょうか。

「すてきな私と、同じになれる」。今日、あなたのフィードに流れてきた広告と、まったく同じ文法です。売っているのは商品の機能ではなくて、それを持ったあなたの、姿のほうです。
