設計メモ

・スマホは2倍解像度で組み、パンチインはスマホプリコンポのscaleで行う(C13アンカーカメラと同じ「Position凍結・注視点駆動」文法。ズーム中も自分サムネが画面中央に張り付く)
・S1字幕帯(下130px)にはスマホの黒ベゼルだけが掛かる。フィードの情報はy<950に収める(縮小不要になる)
・自分サムネのフィード行: チャンネル名「『なんだろう』解体」・「1本目・今日」表記で「今あなたが見ている動画」だと分からせる(メタの核)
・売約済スタンプはサムネ画像には焼き込まず別レイヤーで叩く(実サムネとの差分=「これは劇中の演出」の一線)
・SEキュー: フリック×3(スワイプ音)、停止コツ×3、躊躇は無音(指が止まる音はない方が怖い)、パンチイン各段=低音ドッ(段階的に強く)、スタンプ=ハンコ強打+紙鳴り、グリッチ=短ノイズ
・実装: PhoneFeedHesitation の改修(巨大化・ルームトーン・パンチイン追加)。C06GreenPhoneScreens とは独立
