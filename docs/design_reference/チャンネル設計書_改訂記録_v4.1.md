# チャンネル設計書 改訂記録 v4.1

本差分は『チャンネル設計書 v4(確定版)』11章「法務・規範」の人物規定を**上書き**する。

## 改訂1: 人物の写真・映像(11章)

**旧(v4)**:
> 人物:歴史上の加害者は顔写真不使用・抽象表現のみ。存命人物の顔写真・映像不使用

**新(v4.1) — 3段階ルール**:

1. **私人(一般人)**: 顔は使わない。ぼかし・シルエット・引きで処理【従来どおり・ここは法的リスクが実在】
2. **存命の公人(政治家・経営者・著名人)**: 以下の条件をすべて満たせば使用可
   - 権利クリアな写真(公式広報・CCライセンス・購入素材・報道提供)
   - 公的活動の文脈+論評・解説目的
   - 禁止: 侮辱的な加工/サムネイルでの釣り使用/係争中事案の当事者
3. **歴史人物(故人・加害者を含む)**: パブリックドメインまたはライセンス済みなら使用可
   - 番組の美学(抑制)に従い、資料として淡々と提示する。ヒーロー化も見世物化もしない
   - ナチス関連等は概要欄に教育・解説目的を明示(YouTube収益化対策)

**理由**: 旧規定は法的要請と自主規制が混在し過剰だった。故人に肖像権はなく、
公人の公的活動の論評利用は解説系の標準実務。歴史パートの説得力は本物の顔写真で大きく上がる。
私人の保護と侮辱的文脈の禁止という「本当に危ない部分」は維持する。

## 改訂2: 分類の整理(11章)

「政策・都市の構造回は断罪しない/一次ソースは法律・審議会資料」の規定は**内容を維持**したまま、
分類を「法務」から**「編集方針」**へ移す(法的義務ではなく、陰謀論系と差別化する番組の生命線であるため)。
