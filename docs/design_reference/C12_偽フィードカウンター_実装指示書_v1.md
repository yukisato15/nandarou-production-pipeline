# C12 偽フィードカウンター 実装指示書 v1

2026-07-18 / 承認者: Yuki(偽UI案採用・コンテ表v2のC12行に反映済み)
カットの狙い: ナレ「『経済が終わる』『年金が消える』。こういう言葉は、めちゃくちゃ伸びます。」の
**「こういう言葉」を画面上の実物(C01偽サムネ)で指差し、「伸びます」を回転する再生数カウンターで見せる。**
数字は劇中小道具のダミー値(偽サムネ・偽UIの高彩度例外世界。実データ・実UIの複製ではない)。

## 1. コンポジション仕様

- 名前: `C12FeedCounters` / 1920×1080 / 23.976fps / **264F(11.0s)**(尻はPremiereで調整)
- 背景: ダークUI **#0F0F0F**(YouTubeダーク風だが実UIの複製にしない。ロゴ・実在チャンネル名・実UIアイコンの模倣禁止。C02偽フィードと同じ架空UI文法を流用)
- 納品: `out/ep01/C12_feed_counters.mov`(ProRes 422・フルフレームのため透過不要)
- 乱数不使用。カウンター増分・タイミングはすべて固定値(決定論)

## 2. レイアウト

- **3×2のサムネグリッド**(デスクトップのおすすめ面風・架空UI)。各セル:
  - サムネ画像 480×270・角丸12px・右下に時間バッジ(画像に焼き込み済みのものはそのまま)
  - 下にメタ行: 架空チャンネル名+**再生数カウンター**+「・3日前」等の架空日付
  - メタ行フォントはC02偽フィードと同一(Noto Sans JP)。カウンター数字は等幅(tabular-nums)
- 配置(左上→右下):
  | セル | 画像 | 初期値 | 挙動 |
  |---|---|---|---|
  | 1 | c01/C01_thumb_01.png(日本、終わる) | 1,247,832 | **加速** |
  | 2 | c01/C01_thumb_04.png(今すぐ確認) | 89,120 | 微増 |
  | 3 | c01/C01_thumb_02.png(年金、消える) | 731,455 | **加速** |
  | 4 | c01/C01_thumb_07.png(医者は教えてくれない) | 132,780 | 微増 |
  | 5 | c01/C01_thumb_03.png(知らないと損する) | 966,301 | **加速** |
  | 6 | c01/C01_thumb_05.png(銀行が隠す真実) | 54,209 | 微増 |

## 3. タイムライン(相対F・23.976fps)

| F | イベント | プロパティ |
|---|---|---|
| 0–10 | グリッドがフェードイン(全セル同時・opacity 0→1) | ease-out |
| 0–200 | 全カウンター回転。**微増セル**: +3〜8/F の固定増分。**加速セル**: +40/F から始まり、F60・F120で増分が約2倍ずつ段階アップ(+80→+160/F)。桁の繰り上がりで数字がオドメーター風に転がる | 増分は固定配列。乱数禁止 |
| 60 | 加速セル(1・3・5)のカウンター文字だけ **#FFE600(純黄)** に変色(12Fでクロスフェード)。メタ行の他要素は変えない | 「伸びている」の視覚マーク。番組パレットの金茶は使わない(ここは偽UI世界) |
| 170 | セル1(日本、終わる)以外が **10%減光**(20Fかけて)。視線をセル1へ誘導 | opacity 1→0.9 |
| 200–264 | **セル1の再生数カウンターへズームイン**。scale 100→300%、カウンター数字が画面中央へ。数字は回転し続ける | ease-in(出15/入85)=数字に向かって加速。Position凍結・注視点駆動(C13アンカーカメラ文法) |
| 264 | カット尻。**C13(視線→再生→広告費カウンター)へマッチカット**(数字→数字) | C13冒頭のカウンター位置・サイズに極力合わせる(下記§4) |

## 4. C13とのマッチカット条件(重要)

- C13(AEマスター/AttentionFlow)の冒頭は再生カウンターの数字が画面中央にある状態
- C12の最終フレームで、セル1のカウンター数字を**画面中央・高さ約120px相当**まで寄せて終わること
- 数字のフォントは完全一致しなくてよいが、**サイズと位置を合わせる**(カットが「数字→数字」で繋がって見えることが条件)
- 最終フレームの静止画を `out/qa/C12/last_frame.png` に書き出し、C13の冒頭フレームと並べて確認すること

## 5. 禁止事項

- YouTubeロゴ・実在チャンネル名・実在サムネの使用(素材は c01/C01_thumb_*.png のみ)
- 乱数・Math.random(決定論を壊す)
- 番組パレット(紙・墨・金茶・朱)の使用(このカットは偽UI世界。使う色は #0F0F0F・白・グレー・#FFE600 のみ)
- グラフ・棒・折れ線の追加(データを装う画にしない、が本カットの存在理由)
