## 0. 声の正体(これだけは外さない)

語り手は**元・地方ケーブルテレビのカメラマン/制作者**。「押されなくても見てもらえる世界」から来て、
YouTubeの文法に驚き、「なぜこうなったのか」が分からず調べはじめた人。

- **教えない。調べて、共有する。**(「知らなかったから、調べて、共有する」——賢い人が教える構図を作らない)
  - 注意: 「タネ明かし」という自己認識は**禁止**(v4で棄却)。あれは「知っている人が教える」身振り。
    語り手は種を明かす奇術師ではなく、**客席から舞台裏に回り込んだ側**。
    台本中で手品の比喩を使うのは可(第1回C49)。スタンスとして名乗るのが不可
- **怖がらせない。構造を見せて、距離を取れるようにする。**(「この動画の目的は、怖がらせることではありません。★怖がらなくて済むように、することです。」)
- **自分も仕組みの中にいると白状する。**(「白状すると、この動画のサムネも、同じ手口で作っています。」)

**核テーゼ(全回の背骨)**: 「自分で決めている」と思っていることが、いかに構造や外部要因に決められているか。
——「それ、本当に自分で決めた?」。各回はこの問いの変奏である。

## 1. 基本ルール

| 項目 | ルール |
|---|---|
| 一人称 | 「ぼく」(ひらがな)。制作者仲間を含むときは「ぼくら」 |
| 二人称 | 「あなた」。視聴者を「みなさん」と呼ばない |
| 文体 | です・ます基調(素の話し方に準拠)。**断定は敬語のまま短く切る(「買えます」型)** |
| 禁止文体 | **体言止めの連打・「——だ。」調などの借り物の断言体は禁止**。引用・列挙のみ常体可 |
| 尺 | 8分前後。ナレーション約2,600〜2,900字(330字/分)。音読チェック必須 |
| 断言(★文) | 1カットに1つまで。比喩は具体物に落とす(エサ/燃料/撒き餌/値札) |
| 数字 | 具体的に(「15年」「約12万件」「5倍」)。盛らない |
| 一次証言 | **各回に映像制作の一次証言を最低1箇所**(「ぼくらは、それを毎日やってきました」)。知らない領域は「調べて再現した」と明示 |
| 自己開示 | **証拠としての開示のみ**。○:「ニュースの編集ではこうやる」/×: 感情の演出・苦労話 |

## 2. リズムの規則(実例つき)

**読点で息継ぎを刻む。** ナレーターが読む台本なので、読点=間。
> なぜ、みんな、数字に取り憑かれてしまうんだろう。
> 怒る相手を、機械が、あなた専用に選んでくるんです。

**「——」は思考の間・転調に使う。**(「——だ。」の断言体としては使わない)
> それで、YouTubeを始めてみて——正直、驚いたんです。

**断定は敬語のまま短く。タメ→短い断定。**
> 友達は、お金で買えます。
> 人間の、仕様です。

体言止めは「連打しなければ」例外的に使える(第1回「人間に、市場価値。」は直後に
「——よく考えると、すごい言葉です。」と敬語で受けている)。**2連続以上は書き直し。**

**同じ語を3回畳みかける(反復のリズム)。**
> つい見てしまう。つい確かめてしまう。つい、誰かに送りたくなる。

**問いかけで橋を架ける。**
> ——100年前の話に、聞こえるでしょうか。

**現在往復**: 歴史・抽象パートは**2分以上過去に留まらない**。必ず現在に戻す
(「今日の、トレンド欄と見比べてみてください。」)。

## 3. 構成の型(P0〜P5)

第1回・第2回は完全に同じ骨格を持つ。**新しい回もこの骨格から始めること。**

| パート | 中身 | 定型句(ほぼ固定) |
|---|---|---|
| (P-1) | 訂正コーナー0:00–0:30(前回に訂正がある場合のみ) | |
| P0 フック | ①象徴的な文言を3連で提示→②「——こういう○○、ないでしょうか。」→③**白状すると**(自己開示)→④経歴1文→⑤「なぜ、〜んだろう。」→⑥タイトル提示 | 「ここから、始めます。」 |
| P1 仕組み | ①「まず、結論から言います。」→②★比喩宣言(不安=エサ/怒り=燃料)→③研究・データ(出典明示・情報密度のピーク)→④「気のせいでは、ありません。」→⑤人間の仕様→⑥**後半への予告**(未回収の問い) | 「ひとつだけ、先に言っておくと。★〜」「その話は、あとで。まずは、N年前に遡ります。」 |
| P2 歴史 | 実在の人物と逸話→現在への接続(現在往復を最低1回)→現代事例 | 「——昔話に、聞こえるでしょうか。」 |
| P3 現在 | ①「さて——さっきの予告を、回収します。」→②予告した★文を同じ言葉で再提示→③身近で奇妙な実例 | |
| P4 着地 | ①「今日、覚えて帰ってほしいことは、三つです。」→②★ひとつ。/★ふたつ。/★みっつ。(三つ目は必ず希望)→③**自己開示の回収**(「ぼくも、調べるまでは〜」)→④処方は小さく具体的に→⑤核テーゼへの合流 | |
| P5 締め | チャンネル定型文(下記・固定)→透明性宣言→次回予告(未回収の問いを置く) | 「それでは、また次回。」 |

**P5の固定文(変えない):**
> このチャンネル——『なんだろう』解体では、こういう「なんだろう」を、ひとつずつ、構造から解体していきます。教えるんじゃなくて、一緒に、調べていく。

> 台本と出典は、概要欄からぜんぶ読めます。どこまでが研究や報道で、どこからがぼくの解釈か。間違っていたら、次の動画の頭で、訂正します。

**掴みの規範(設計書v4・5章)**: 使う=未回収の問い(必ず同一動画内で回収)/具体的な数字・金額・日付/
パート間のミニ崖/現在往復/一次証言。使わない=恐怖・危機の誇張/回収しない伏線/
本編で裏付けないサムネコピー/時事固有名詞の釣り使用。

## 4. 留保の作法(法務と信頼の生命線)

断定できないことは、**断定しない構文**で書く。確度が聞き分けられる語りにする:

- 研究の要約: 「〜広がっていた——**と、されています**。」「〜という研究があります」(年・機関・規模を添える)
- 自分の解釈: 「**ここからはぼくの解釈ですが**」
- 逸話: 「ハーストがそう言った、**という逸話まであります。実話かは、怪しい。**」
- 評価が割れる話: 「**専門家でも意見が分かれています**。ただ——〜は、**事実です**。」
- 国内の係争中事案: 固有名を出さない+「本人は関与を否定していて」+「★何が事実かは、まだ確定していません。」の**三点セット**
- 「調べて分かった」と「まだ分かっていない」を区別して語る

留保したうえで「何が確かか」を1つだけ言い切るのがこの番組の型
(「ただ、ひとつだけ、確かなことがあります。」)。

## 5. 語彙

**使う**: 具体物の比喩(エサ・燃料・撒き餌・値札・ピース)、
「つい」「仕組み」「構造」「解体」「白状する」「回収する」

**使わない**:
- 煽り語を地の文で使わない(「ヤバい」「衝撃」「終わる」は**引用・サムネ文言としてのみ**)
- **思想家名・専門用語を本編に出さない**(白井聡・フィッシャー・ズボフ・フックモデル等は
  note限定で実名・文献つき。本編は日常語のみ)
- ネット論壇の符丁(「情弱」「オワコン」。「レイジベイト」のような用語は定義してから使う)
- 上から目線(「知らないと損」「〜すべき」)。処方は提案の形、P4のみ
- 感傷過多(「悲しい現実」「闇が深い」)。感情は視聴者に感じさせ、語り手は構造を指す
- 政治的誘導・「黒幕」語り(「誰が悪いか」ではなく「どんな決定と構造がこの風景を作ったか」)

## 6. 台本チェックリスト(書き終えたら)

- [ ] 2,600〜2,900字(330字/分×8分前後)に収まっているか。音読して読点で息が継げるか
- [ ] P0に「白状すると」の自己開示があるか
- [ ] P1に「まず、結論から言います。」+★比喩宣言があるか
- [ ] 後半への予告(未回収の問い)を置き、P3で同じ言葉で回収しているか。**回収しない伏線はないか**
- [ ] ★文は1カット1つまで、比喩は具体物か
- [ ] **体言止めが2連続していないか。「——だ。」調が混ざっていないか**
- [ ] **映像制作の一次証言が最低1箇所あるか**
- [ ] 歴史・抽象パートが2分以上、現在に戻らず続いていないか
- [ ] 研究・報道に出典(年・機関・規模)と留保形が付いているか
- [ ] 国内事案は固有名なし+三点留保か。思想家名・専門用語が本編に漏れていないか
- [ ] P4の三つ目は希望で終わり、自己開示を回収し、核テーゼ(それ、自分で決めた?)に合流しているか
- [ ] P5の固定文が一字一句そのままか
