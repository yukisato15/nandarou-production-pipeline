## 4. 1枚あたりの飛行仕様(共通)

- **出現(相対F0–2)**: scale 420% / opacity 0→1 / blur 6px / 回転は着地値±3°から収束
- **飛行(相対F0–着地)**: scale 420→100% を指数ease-out(**出85/入15**)。blurはscale進行に連動して6px→0
- **出現位置**: 着地スロットの対角象限側に画面外周からオフセット(スロット1=右上から、2=左下から、3=正面やや上、4=左から、5=右から、6=上から、7=右下から。開始中心=着地中心+対角方向に(±420, ±260)の固定オフセット)
- **着地(3F)**: scale 100→97→100 のオーバーシュート+画面全体グロー(白オーバーレイ 0→peak→0、3F)+**スタック全体が+3px沈み2Fで復帰**
- グロー・沈みは着地したサムネ以外(既着地の全レイヤー)にも掛かる(=画面が「揺れる」)

## 5. 実装上の注意

- zodスキーマ: `images: string[]`(7枚)+`durationInFrames?`。座標・タイミング・グロー等の演出値はpropsにしない(本仕様が唯一の正)
- blur/scale/glowの補間は `interpolate` + `Easing.bezier` で決定論的に。乱数不使用
- モーションブラーHOCは使わない(scale連動blurで足りる。重い)
- `remotion_mg/data/ep01_scenes.json` のC01エントリを7枚構成に更新(旧3枚構成のprops形は廃止してよいが、schema変更内容をコミットメッセージに明記)
- 旧「上からフレームイン」実装は削除(git履歴に残る)
