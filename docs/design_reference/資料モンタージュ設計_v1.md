# 資料モンタージュ設計 v1 — Remotionを「モンタージュ編集台」として使う

2026-07-14 / Yuki検証 → Fable整理
上位: `Remotion基盤_調査設計_v1.md`(Remotionの第一の役割=情報カット自動生成)の**続編**。
本書はRemotionの**第二の役割**を定義する。

---

## 0. 何が分かったか(検証の結論)

Remotionは「JSONから図解・グラフ・テロップを自動生成する仕組み」だけではない。
**実写動画・静止画・紙背景・切り抜き・数字・注釈・モーションを重ねる「コードで制御できる
モンタージュ編集台」**としても使える。海外ドキュメンタリー(VOX的)の資料モンタージュを、
生成AIに頼りきらずに、要所で自前生成できる。

### 検証で実際にできたこと(船・波動画・紙背景の3素材)
- 紙/テクスチャ背景の上に、実写写真や切り抜き画像を重ねる
- ふつうの海動画から**波部分だけをクロップ**して背景に使う(素材が透過でなくてよい)
- 切り抜いた戦艦を波の上に重ね、左→右へスライド
- 波は常時動かし、船の移動後に数字カウンターを出す(0→9,000人 のアニメーション)
- シンボルアイコンを差し替え可能(オイルバレル→日章旗)
- 下部字幕だけでなく、紙背景になじむ**見出しテロップ**も出せる
- クロップ・スケール・位置・速度・質感を Studio props から調整

### 最大の教訓: 素材は「完成品」でなくてよい
Remotion側で、素材の下ごしらえまで引き受けられる。
- 波動画が透過でなくても → クロップして波部分だけ使う
- 船画像が大きな白背景の中に小さくあっても → トリミング＋白背景の簡易キーで抜く
- 紙・実写素材も → グレースケール/コントラスト/マスク/ブレンド/スケールをコードで調整

→ 「素材が集まりきらない/生成AIのコストが嵩む」場面を、Remotionモンタージュが埋める。

## 1. 位置づけ — Remotionの二つの役割

| 役割 | 何を作るか | 実装 | 状態 |
|---|---|---|---|
| ① 情報カット生成 | グラフ・年表・引用・宣言・タイトル(抽象・データ) | JsonScenes + レジストリ | 実装済み |
| ② **モンタージュ編集台** | 実写+静止画+紙+数字+注釈を重ねた資料モンタージュ(具体・映像的) | MontageScene(下記・設計) | **本書で設計** |

両者は同じ基盤(theme/stages/registry/zod/カット単位の透過MOV書き出し)を共有する。
①が「机の上の資料」なら、②は「机の上で資料を動かして見せる」。**LOOK(紙・墨・グレイン・
金茶朱)は完全に共通**——モンタージュも番組の資料机の中で起きる。

### 生成AIとの関係(補完であって置き換えではない)
- 生成AI動画(Runway・Gemini)は引き続き主力。歴史・抽象・「その場に居合わせた画」に強い
- Remotionモンタージュは**要所**で使う: 資料(写真・地図・切り抜き)を構造的に見せる、
  数字を動かす、複数素材の関係を示す、生成AIでは高コスト/不安定な「正確な図示」を担う
- 判断は §4 の早見表

## 2. アーキテクチャ(①と同じ2ループに乗せる)

```
コンテ(素材ソース=「Remotion(モンタージュ)」/ MGテンプレID=MNT_*)
   ▼
モンタージュJSON (MontageDoc: 背景 + レイヤー配列[各レイヤーにcrop/scale/pos/motion/grade/blend])
   │  zodスキーマで検証(①のScenesDocと同じ思想)
   ▼
MontageScene コンポジション(レイヤーを時間軸で重ねる)
   ▼
カット単位の透過ProRes4444 → Premiere(編集席)
```

- **制作ループ**: JSONだけを書く。素材は `public/footage/` `public/cutouts/` `public/photos/` に置く
- **拡張ループ**: 新しいレイヤー型・演出が要るときだけコンポーネントを起案→Studioで人間承認→登録
- 書き出しは①と同じ**カット単位**(実編集のTC目安ズレに強い。`render_telops_per_cut.sh`と同方式)

## 3. 部品カタログ(設計 — 実装は承認後)

MontageSceneのJSONで組む。1シーン=背景1つ + レイヤー複数。

### 背景(いずれか)
- `paper` / `texture` — 紙・テクスチャ(theme のテクスチャを流用)
- `ink` — 墨
- `media` — 実写動画/静止画を背景に(クロップ可。例: 海動画の波部分だけ)

### レイヤー型(layers[] の要素)
| type | 用途 | 主なprops |
|---|---|---|
| `media` | 実写動画・写真を重ねる | src, crop{x,y,w,h}, objectFit, scale, pos, speed, loop, grade{grayscale,contrast,brightness}, blend, mask, opacity |
| `cutout` | 白背景を抜いた切り抜き(船・人・物) | src, key{lumaThreshold}, trim, scale, pos, motion{from,to,easing}(スライド) |
| `counter` | 数字カウントアップ | from, to, suffix(人/円/%), icon(差し替え可), duration, easing, pos |
| `paperHeadline` | 紙資料風の見出し(下部字幕でない) | text, pos(左上等), 罫, emphasis《》 |
| `annotation` | 矢印・丸・ラベル・引き出し線 | kind(arrow/circle/label), from, to, text, color(墨/朱/金茶) |
| `caption` | 下部の注記・出典 | text, source, conceptual |

共通: 各レイヤーは `appearAt`(秒)/`duration` を持ち、①と同じ「読める尺」の考え方を適用。
色は theme(紙・墨・金茶・朱)、数字は Oswald、見出しはしっぽり明朝。**新しい色・書体を発明しない**。

### 素材の下ごしらえ(コード側で完結)
- **crop**: 元動画/画像の使いたい矩形だけを切る(透過素材でなくてよい)
- **key**: 白/単色背景の切り抜きを簡易キーで抜く(完璧でなくてよい・資料質感に馴染ませる)
- **grade**: グレースケール/コントラスト/セピアで番組ルックに寄せる(実写の彩度を殺して墨紙に馴染ませる)
- **blend/mask**: 紙にプリントしたように馴染ませる(multiply等)/縁をぼかす

## 4. 使い分け早見表(モンタージュ vs 生成AI vs 実写/ストック)

| 見せたいもの | 第一候補 |
|---|---|
| 資料写真・地図・切り抜きを構造的に(関係・変遷・内訳) | **Remotionモンタージュ** |
| 数字を動かす/アイコンで象徴化(人数・金額・比率) | **Remotionモンタージュ**(counter) |
| 「その場の空気」実写(街・生活・手元) | Envato/自分で撮影 |
| 歴史・抽象・再現不能な情景 | 生成AI(Runway/Gemini) |
| 純粋なグラフ・年表・引用・宣言 | Remotion情報カット(①/JsonScenes) |
| 偽サムネ・偽UI(番組の外の世界) | Canva/Photoshop+AI画像 |

原則: **生成AIが高コスト/不安定になる「正確な図示・資料の再構成」はモンタージュへ寄せる。**
Envato等の既存素材も、生で貼るだけでなく Remotion上で再構成してよい(クロップ・グレード・合成)。

## 5. 番組ルック・法務との整合(既存規則をそのまま適用)

- LOOK: 紙#E3DED1 / 墨#0E0F10 / 金茶#C9A063 / 朱#B8352E + グレイン/ビネット。実写は彩度を落として馴染ませる
- 禁止: 意味のない英字装飾/明るいダッシュボード風/画面ごとの意匠発明(モンタージュでも同じ)
- 出典: 資料写真・データには出典を常設。演出値は「※概念図」
- 人物写真: v4.1の3段階ルール(私人=顔NG / 存命公人=権利クリア+論評文脈 / 歴史人物故人=PD)
- 実在ロゴ・実在紙面・実在サムネは使わない(切り抜き・見出しは架空/PD素材で作る)
- 素材の権利: Envato等はライセンス範囲内。切り抜き元も権利クリアのものだけ

## 6. 具体例(検証シーンの再現=戦史モンタージュの型)

> 紙背景の上に海の波動画を下部クロップで重ね、切り抜いた戦艦を左→右へスライド。
> 船の移動後、右に日章旗アイコンとともに 0→9,000人 のカウンター。左上に紙資料風見出し
> 「日本軍はレイテ沖に進軍」。10秒前後、ナレーションに同期。

この型は歴史パート(第2回C22–C29のメディア史=新聞・ラジオ等)に直接応用できる。
※本番採用時は史実の数値・固有名の裏取りと出典明記、係争・現存事案の留保規則を厳守。

## 7. 次の一手(実装は人間承認後)

1. `MontageScene` コンポジション + zod スキーマ(背景+レイヤー配列)
2. レイヤー型 `media` `cutout` `counter` の3つを先行実装(検証シーンが再現できる最小集合)
3. 検証シーン(船・波・紙)を MontageDoc として作り、静止画→動画で番組ルック確認【人間ゲート】
4. 承認後 registry に登録、`使い方マニュアル.md` に「モンタージュの作り方」を追記
5. 歴史パートの1カットで実戦投入 → 使い勝手をコンテ表の語彙に反映
