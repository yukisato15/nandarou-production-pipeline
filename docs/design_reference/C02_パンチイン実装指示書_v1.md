## 2. コンポジション

- `PhoneFeedHesitation` の改修(または後継 `C02PhoneFeedPunchIn`)。1920×1080 / 23.976fps / フルフレーム
- 背景: ルームトーン #0A0B0C+ビネット34%+グレイン(グリッチコラージュ背景は廃止。C01と同一のInkStage系ステージを流用)
- スマホ: 幅620px相当・中心(960,470)・回転−2°固定・画面上下見切れ。**2倍解像度で組み、Position凍結・scale駆動**(C13アンカーカメラ文法)
- フィード行のメタ情報(チャンネル名・視聴回数)は架空。自分のサムネ行だけ「『なんだろう』解体・1本目・今日」
- S1字幕帯(下130px)にはベゼルのみ掛かる。フィード情報はy<950に収める

## 3. モーション(スタイルフレームHTML §仕様表のとおり)

要点のみ再掲: フリック×3(blur連動・指数ease-out)/偽サムネ停止+躊躇(−3px戻し×2)/自分サムネ停止(※「白状すると」同期点)/パンチイン3段(118%→160%→260%、各段シェイク)/売約済スタンプ強打(280→100%・3F・−14°・全体+4px沈み)/白フラッシュ1F(.12)/**クリーンな決め画をホールド**(グリッチなし・v1.1)→C03へはPremiereでハードカット

- スタンプはサムネ画像に焼き込まず**別レイヤー**(実サムネとの一線)
- 乱数不使用。シェイクは固定オフセット配列で決定論化

## 4. 透過納品(v1.1・C01/C02共通の新ルール)

- **レンダーに含める**: スマホ本体・フィード・サムネ群・スタンプ・シェイク/沈み・白フラッシュ
- **レンダーに含めない**: ルームトーン背景・ビネット・グレイン(ステージ層)。`bg: 'none'` 等のpropsでステージを無効化できるようにする
- 書き出し: `--codec prores --prores-profile 4444`(アルファ付き)。ファイル名は `.mov`
- 背景は別素材として納品: ルームトーン(#0A0B0C+ビネット34%)の**静止画PNG 1920×1080** を `out/ep01/bg_roomtone.png` に書き出し(C01/C02共用。Premiereで下に敷く)
- グレインはPremiereの調整レイヤーで全体に掛ける(番組LOOKとして一元管理)
