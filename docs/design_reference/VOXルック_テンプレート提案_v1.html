VOX風モンタージュ・テンプレート提案 v1

目的: 現行の「静かな異物感」の資産(明朝・墨・金茶・朱)を捨てず、VOXの見やすさ・写真モンタージュの迫力を接ぎ木する。 下は実際の第1回カットに当てて組んだテンプレ案。写真はCSSの擬似アーカイブ画像(実装では実写/PD/AI画像)。

結論を先に: 全面VOX化(極太ゴシック+高彩度)は勧めません——それは他の解説チャンネルと同じ顔になり、差別化(明朝の声)を捨てることになります。 勝ち筋は「VOXの構図・カメラ・データの見せ方 × この番組の明朝と抑制パレット」。 つまり写真は全面・グレード強め、文字は明朝のまま大きく、色は金茶/朱を一点だけ。これなら"誰も持っていないモンタージュ・ルック"になります。

テンプレA — アーカイブ・ロワーサード(人物・歴史の導入)

全面のアーカイブ写真をグレード(グレースケール+コントラスト+暗め)。左上にソースタグ、下に大型明朝の見出し。VOXの基本形。使用カット例: C25 バーネイズ登場 / C42 ゲッベルス。

実装への落とし方

・theme.tsに琥珀#E8A33Dとグレードのプリセット(archive: grayscale.75/contrast1.15/brightness.72、quote: .9/1.2/.5)を追加
・新レイヤー型ArchiveLowerThird / FullBleedStat / QuoteOverPhoto / MontageBoardを上のA〜Dとして起案 → 静止画承認 → registry登録
・これらはMontageScene(資料モンタージュ)の具体テンプレになる。つまり今回の転換は方針転換ではなく、設計済みの②モンタージュ路線を"VOX品質で確定させる"作業
・チャンネル設計書v4.4(質感設計の改訂)+ブランド定義への追記が必要(全面写真の許可・琥珀の追加・Ken Burns標準化)
・既存の墨タイトル/★宣言/偽UIはそのまま共存(全部をVOX化しない。"静かなカット"は残す=緩急がVOXらしさでもある)
一点だけ強く言います: VOXが格好いいのは"派手だから"ではなく徹底した引き算だからです。1画面に情報を詰めない・色は一つ・余白を大きく取る。 この番組の「抑制」の美学は、実はVOXと同じ方向を向いています。だから恐れず寄せて大丈夫。危険なのは"VOX風の派手さ"だけ真似て情報過多になること。それだけ避ければ、むしろ番組の核が強化されます。
