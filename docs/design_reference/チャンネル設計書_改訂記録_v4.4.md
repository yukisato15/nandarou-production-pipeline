## 改訂1: 素材ソースの優先順位を「モンタージュ優先・生成AI最後」へ

**方針転換の核**: **生成AIの"動画"を減らし、"静止画"はモンタージュの主力の餌にする。**
静止写真(生成AI・PD・自撮り・ストック)をRemotionモンタージュでクロップ・グレード・移動・合成して
映像化する。狙いはクオリティ向上とコスト・安定性。

**重要な区別(2026-07-18・Yuki確認)**:
生成AIには2つの用途があり、扱いが正反対。
- **生成AI"静止画"(人物切り抜き・背景プレート・テクスチャ) = 主力の素材**。
  Geminiで「スマホを見る人物」「コンクリ/アスファルトのテクスチャ板」などを作り、切り抜いて
  モンタージュ上で動かす——これが現時点のベストプラクティス(添付リファレンス画のワークフロー)。
  静止画は正確・安価・権利が明快で、動きはRemotionが与える
- **生成AI"動画"(Runway等の生成ムービー) = 減らす**。高コスト・不安定・"それっぽい嘘"。
  静止画モンタージュで作れないか、を必ず先に検討する

**新・素材ソースの選択順**:

1. **第一候補: Remotion写真モンタージュ(MNT_*)** — 素材は【生成AI静止画/PD/自撮り/ストック】。
   クロップ・グレード・Ken Burns・切り抜きスライド・波/煙などの実写合成で"動く映像"にする。
   歴史・資料・人物・データの大半をここで作る
2. Remotion情報カット(RMT_*) — グラフ・年表・引用・宣言・タイトル(VOXデータ・テンプレで全面写真化)
3. ストック実写/自撮り — 「その場の空気」+モンタージュの素材(波・煙・群衆・手元)
4. 偽サムネ/偽UI — 番組の外の世界(高彩度例外)
5. **最後の手段: 生成AI"動画"(Runway/Gemini動画)** — 静止画モンタージュで作れない、
   再現不能な動きの情景に限定

**旧v4.2「生成AIは引き続き主力」を、"生成AI動画は補完に降格・生成AI静止画は主力素材"へ再定義。**

## 改訂2: 質感設計の更新(8章・v4.2をさらに上書き)

- **全面写真を主役化してよい**(旧: ストック生使用は避け気味)。ただし §grade プリセットで
  番組ルック(墨・紙・低彩度)へグレードすること。彩度が浮いた生写真の貼り付けは不可
- **静止写真には緩速カメラ(Ken Burns)を標準適用**。静止画を"止まった資料"のまま置かない
- **実写(波・煙・光・群衆)は質感の下地として少量**。生で全面に使うより、モンタージュ上で
  クロップ・グレードして重ねる
- 維持: 明朝の声 / 低彩度(高彩度は偽サムネのみ)/ グレイン・ビネット / 区間ごとの質感切替=見せ場

## 改訂3: パレット追加

- **琥珀 `#E8A33D` を追加**(数字ハイライト専用)。明るい全面写真の上で金茶が沈むため。

## 改訂4: VOXデータ・テンプレA〜Dを標準テンプレに採用

承認済みスタイルフレーム(`VOXルック_テンプレート提案_v1.html`)のA(アーカイブ・ロワーサード)/
B(全画面データ)/C(引用)/D(資料モンタージュ)を、情報カット・モンタージュの標準構図とする。
実装はMontageSceneのレイヤー合成(独立コンポーネント化しない)。
