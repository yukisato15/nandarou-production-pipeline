# C01 偽サムネ×3 制作仕様 v1

スタイルフレーム: `C01_fake_thumbs_styleframe.html`(ブラウザで開いて確認。構図・文言・配色の確定用)

## 設計原則

- 偽サムネは「番組の外の下品な世界」。**番組パレット(紙・墨・金茶・朱)を意図的に破る。**
  使う色は YouTube 煽り文法の 純黄 `#FFE600`・純赤 `#E60012`・黒 `#111`・白。
- フォントは極太ゴシック(ヒラギノ角ゴ W9 / Noto Sans JP Black / ゴシックMB101 相当)。しっぽり明朝は使わない。
- 3枚は別ジャンルの煽りに見せる(経済崩壊系/老後不安系/情報商材系)。同一人物・同一レイアウトに見えると「自作感」が出る。
- 右下に再生時間バッジ(10:24 等)を入れて実在感を出す。実在チャンネル名・ロゴ・実在人物は入れない。
- 明暗リズム: ①暗 → ②白 → ③黄。スタック時に画面の印象が毎回変わるようにする。

## 各サムネ

### ① 「日本、終わる」(経済崩壊系・暗)
- 背景: 黒〜暗赤のラジアルグラデ+下落する赤い折れ線(グロー付き)
- 左1/3: AI画像 = 40代日本人男性、スーツ、両手で頭を抱えて驚愕、口が開いている、暗い部屋、顔に赤いモニター光、望遠、過剰な表情
- 【緊急】赤帯(左上、白抜き、斜めカット)
- 「日本、」白 →「終わる」黄・特大・黒フチ、全体を-2°回転
- 右下に小さく「※もう間に合いません」(白、赤グロー)

### ② 「年金、消える」(老後不安系・白)
- 背景: 白〜生成りのワイドショー文法
- 上端: 黄色帯「知らないと危険」黒文字+黒の下罫
- 「年金、」黒 →「消える」赤・白フチ、背後に黄色マーカー(skew)
- 右半分: AI画像 = 日本の高齢者のしわのある両手が年金手帳と銀行通帳を持つ、俯瞰、蛍光灯、生活感、ドキュメンタリー写真風
- 通帳の上に「¥0」黒・白フチ、赤の手描き風楕円+赤矢印

### ③ 「知らないと、損する」(情報商材系・黄)
- 背景: 純黄+集中線(低透明度の黒)
- 左上: 赤丸バッジ「9割が/知らない」白フチ、-12°回転
- 「知らないと」黒 →「損する」赤・白フチ
- 右: AI画像 = 30代日本人男性、カメラ目線で人差し指を突き出す、口を開けて訴える表情、リングライト、YouTuber風、上半身、背景単色
- 赤の手描き風カーブ矢印(文字下→左へ)

## 制作フロー

1. AI画像3点を生成(人物は日本人。表情は「サムネ用に過剰」と明示する)
2. Photoshop / Canva でスタイルフレーム通りに文字・図形を載せる(ここは人間の仕上げ)
3. 1280×720 PNG で書き出し → `assets/mg/c01/C01_thumb_01.png` 〜 `03.png`
4. AE 側は既存 `AE_CARD_STACK_THUMBNAIL` パラメータ(位置・回転・delay・105→100%ドン・最終微ズーム)で**スタックのみ**行う。サムネの中身をコードで描かない

## コンテ表への反映(要修正)

- コンテ表 C01 の MGパラメータJSON `cards[].accent` が番組パレット(#B8352E/#C9A063/#EAE6DF)のまま。
  カードをコード描画しなくなるため、`accent` は廃止し `image` (ファイルパス)へ差し替える。
- `card_size: [1040,360]` は16:9でない。画像スタックでは `[1120,630]`(16:9)等へ変更。
