この検証シーンで確認すること(人間ゲート2)

・collage背景が番組ルックに馴染むか: 低彩度グレードで墨×金茶に収まり、偽UIの純黄だけが差し色として浮く(高彩度の同居が破綻しないか)
・切り抜き人物が「板の上の物」に見えるか: 影・縁ぼかし・グレードで背景と一体化しているか
・微視差とKen Burnsで「静止画が生きて」見えるか(生成AI動画なしで映像に見えるか=この転換の成否)
・labelBox・矢印・ソースタグの図解可読性(VOXの見やすさ)
・書き出し: 透過ProRes4444+背景別出し、決定論(微視差の乱数は`random(seed)`)
