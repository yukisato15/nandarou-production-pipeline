だから、これが大規模にやられたとき何が起きるかは、気のせいの話ではありません。ちゃんと研究があります。

## パート2A 欲望を発明した男——バーネイズ(3:30–6:10)

《画:1920年代ニューヨーク(AI生成・セピア)。摩天楼、群衆》

100年前のアメリカに、エドワード・バーネイズという男がいました。心理学者フロイトの、甥です。

彼が書いた本に、こんな一節があります。

《画:S3引用カット(『プロパガンダ』1928より)》

「私たちが自由意思で行っていると考えている日常の選択は——姿の見えない統治機構の、支配を免れない」。

自分の意志で選んでいるつもりの買い物も、投票も、外から与えられたイメージに形づくられている。——それを「操る側」として書いた本です。書いたのは、実際に操ってきた本人です。

彼の最初の大きな仕事は、商品ではなく——戦争でした。第一次世界大戦で、世論を参戦に向けて動かす政府の仕事に就き、言葉が大衆を動かす力を、実地で目撃します。

戦争が終わったとき、彼が何を考えたか。晩年の、本人の言葉が残っています。

《画:S3引用カット(BBC制作ドキュメンタリー・2002収録インタビューより)》

「戦争に使えたのなら、平和のためにも使えるはずだ。ただ、プロパガンダという言葉は評判が悪くなった。だから、別の言葉を探した。——それが、パブリック・リレーションズ」。

PR。広報。——ぼくらが毎日聞いているあの言葉は、プロパガンダの言い換えとして生まれました。

《画:1920年代の実用広告(ケチャップ・自動車・靴)》

当時の広告は、商品の「必要」を売っていました。料理のためのケチャップ、移動のための自動車。そこに、ウォール街の銀行家がこう書きます。1927年です。

《画:S3引用カット》

「アメリカを、必要の文化から、欲望の文化へ切り替えねばならない。まだ使えるものを持っていても、人々が新しいものを欲しがるように、訓練するのだ」。

——訓練。すごい言葉です。その転換の、いちばん巧い実行者がバーネイズでした。

《画:たばこ・パレード(AI生成・抽象寄り)》

1920年代の終わり、たばこ会社が彼に相談します。「女性にも、たばこを吸わせたい」。女性が外でたばこを吸うのは「はしたない」と、された時代です。

バーネイズは、精神分析の医者に相談しました。返ってきた助言は、こうだったといいます。——たばこは、力の象徴だ。女性にとっては、自分の「たいまつ」になる。

1929年、ニューヨークのイースターパレード。彼は若い女性たちを雇って行進に混ぜ、合図とともに、一斉にたばこへ火をつけさせました。報道各社には、事前に知らせてあります。「明日、"自由のたいまつ"が灯ります」と。

翌日の新聞が、その画を「女性解放の象徴」として全国に運びました。

★デモに見えたものは、広告でした。

ここで売られたのは、たばこの味ではありません。「私は、古い女性とは違う」——**それを、まわりに見せること**です。こういう買い方に、130年前の経済学者が名前をつけています。「見せびらかしの消費」。モノではなく、モノが表す「自分」を買う。

★商品そのものではなくて、「それを買うと、どんな自分になれるか」を売る。

《画:一瞬で現代へ。フィードの広告とインフルエンサー投稿(自作モック)》

——100年前の話に、聞こえるでしょうか。「すてきな私と、同じになれる」。今日あなたのフィードに流れてきた投稿と、まったく同じ文法です。

《画:黒み。2つのアイコンが並ぶMG(「怖い」と「なりたい」)》

さて。ここまでで、種類の違うエサが、2つ出てきたことに気づいたでしょうか。

★人を動かすエサは、大きく2つです。「こうなったら怖い」という不安。「こうなりたい」という欲望。

不安は、確かめずにいられなくする。欲望は、欲しがらずにいられなくする。バーネイズは、この2つのレバーを見つけて、体系にした人です。そして——このレバーは、商品を売る以外にも、使えてしまう。

### 国内事案・固有名版(ALT)についての制作判断メモ

- 設計書§11:「係争中事案:固有名は原則ぼかす。出す場合は両論留保+出典明記」——出す場合の条件は満たせるが、以下のリスクを認識の上で判断すること:
  1. 報道側に一部訂正が出ている事案のため、真実相当性の足場が弱い(名誉毀損リスクはぼかし版より一段高い)
  2. 初投稿で現職政権の固有名を出すと、アルゴリズム・コメント欄の両面で「政治系チャンネル」として分類され、エバーグリーン戦略と番組の中立ポジションに長期の影響が出る
  3. 固有名の情報価値は低い(ニュースを追っている人には自明、追っていない人には無意味)のに対し、リスクは非対称に大きい
  4. ロードマップ#14が「係争決着後に固有名で深掘り」を予定済み——そのときに出す方が、事実も固まり、番組の「回収する」美学とも一致する
- 以上より草稿はぼかし版を本文とした。固有名版を採る場合は、ALT文言+概要欄への出典列挙(複数報道+訂正発表含む)+公開前の法的確認を推奨
