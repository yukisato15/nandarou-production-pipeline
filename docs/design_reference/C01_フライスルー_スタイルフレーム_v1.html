設計メモ

・背景変更(グリッチコラージュ→ルームトーン)の理由: サムネ7枚が全て高彩度(劇中小道具の例外)のため、背景まで騒ぐと占拠の恐怖が薄れる。暗い部屋に通知が飛んでくる、が体験の正体
・サムネのCSSはプレースホルダ。実装は既存PNG(c01/)+バリエーション4枚(要制作 or feed_thumb流用)を差し替え
・飛来の出現位置は「毎回違う象限」だが乱数にせず上表の固定値(決定論・再現性)
