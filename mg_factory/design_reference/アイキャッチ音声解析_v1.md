## 発話・無音境界

`ffmpeg silencedetect=noise=-45dB:d=0.03` でボイスのみを解析した。下表の「なんだろう」「解体」の対応は、支給仕様に記載された発話順と音声エネルギー区間を対応づけたもの。音節単位の字幕点灯ではなく、演出の開始・終了基準として使う。

| イベント | 秒 | 30fpsフレーム（秒×30） |
|---|---:|---:|
| ファイル開始 | 0.000000 | 0 |
| 実質音声開始 / なんだろう開始 | 0.226312 | 6.789 → 7 |
| なんだろう終了（次の無音開始） | 1.686083 | 50.582 → 51 |
| 解体開始（無音終了） | 2.578729 | 77.362 → 77 |
| 解体終了（末尾側の無音開始） | 3.031146 | 90.934 → 91 |
| ファイル終了 | 5.505500 | 165.165 → 166（尺） |

ボイスのみの追加無音境界は 2.777917–2.835167秒（83–85F）。これは解体中の短い息継ぎ／音節間隙として扱い、画面を完全停止させる合図にはしない。

## ステム同期

3ファイルとも同一の5.505500秒、48kHz、2chで、冒頭と終端の無音境界が一致している。completeとSE-onlyには 4.940688秒以降に短い低レベル区間が共通して現れるため、タイムラインは同期していると判断した。完成版を再生するCompositionではSE/voiceを重ねず、音声モードを排他的に切り替える。

## 実装上の基準

- `src/ident/timing.ts` に秒数から決めたフレーム値を集約。
- HUD/解体処理は77Fから起動、タイトル完成は101F、156Fから映像のみフェード。
- 完成版のピークが0.0dBFSのため、Remotion側で勝手にマスタリングせず、支給ミックスを基準音源として再生する。
